Plataforma Institucional Cloud

Sistema de Gestión de Prácticas Profesionales

Plataforma integral desarrollada para el Taller Evaluativo 3er Corte. Articula una base de datos MySQL 8 en la nube (Railway), una API REST con Node.js y Express, y este portal de consumo en tiempo real.

Presentación General del Proyecto

El sistema digitaliza y automatiza el ciclo de vida de las prácticas universitarias, garantizando la trazabilidad entre estudiantes, programas académicos, corporaciones en convenio y tutores institucionales.

1. Base de Datos Cloud

MySQL 8 en Railway con 6 tablas relacionadas en Tercera Forma Normal (3FN), integridad referencial estricta y 10 registros reales por tabla.

2. API REST Node.js

Arquitectura en capas (configuración, modelos, controladores, rutas) desplegada en Railway con soporte CRUD completo y respuestas JSON consistentes.

3. Portal Web

Visualización interactiva responsive con navegación entre las 4 páginas requeridas y consumo en vivo mediante fetch/shortcode.

Reglamento y Proceso de Prácticas

Marco normativo institucional para el desarrollo de la modalidad formativa de grado.

Fases del Proceso de Prácticas

  1. Fase 1: Preinscripción y Verificación Académica: Haber aprobado mínimo el 80% de los créditos del plan de estudios.
  2. Fase 2: Asignación y Formalización de Convenio: Suscripción del acuerdo marco y legalización de afiliación a ARL.
  3. Fase 3: Ejecución y Acompañamiento: Cumplimiento de 320 horas formativas bajo supervisión bimensual del tutor institucional.
  4. Fase 4: Evaluación y Calificación: Nota académica del tutor (40%), calificación de la empresa (40%) y sustentación de informe final (20%).
Requisito Esencial: La práctica profesional no puede iniciarse sin la asignación previa del tutor académico y la validación de afiliación a la Administradora de Riesgos Laborales (ARL).
